MANUAL DE USUARIO MÓVIL · SOLO FRONTEND

MANUAL_DE_USUARIO_MOVIL

Manual técnico-pragmático, ultra explicado, interactivo y pensado para que cualquier persona pueda usar el frontend de la app móvil Kaffa sin conocimientos previos. Se documenta únicamente lo visible e interactuable desde la interfaz.

Aplicación: Kaffa (Android · Jetpack Compose) Alcance: ÚNICAMENTE FRONTEND Formato: HTML Interactivo + PDF + DOCX Capturas: Reales desde doImagenes_manual/
1. Objetivo, alcance y público

¿Para qué sirve este manual?

Guiar paso a paso el uso del frontend de Kaffa por rol, mostrando pantallas, acciones, botones, flujos visuales y resultados esperados. No se documenta lógica de negocio, repositorios, DTOs ni endpoints.

Objetivo

Aprender usando la app

Explicar de forma clara, directa y visual cómo interactuar con cada pantalla: navegación, autenticación, carrito, pedidos, paneles por rol y elementos comunes.

  • Orientado a novatosLenguaje coloquial, pasos numerados y "acción → resultado".
  • Solo lo que se veSe centra en UI, rutas, diálogos, estados visuales.
  • InteractivoNavegación lateral, búsqueda, lightbox para ampliar capturas.
Alcance

Qué cubre / qué NO cubre

  • SÍ: FrontendSplash, Login/Register/ForgotPassword, Home/Client, Productos, Carrito/POS (vista), Pedidos, Perfil, Chat, Barista (Panel/Kanban/Caja), Admin (Panel/Catálogo/Usuarios/Reportes/Gestión), Componentes, Tema claro/oscuro.
  • NO: BackendAPI, validaciones de servidor, repositorios, mapeo DTO, reglas de negocio, base de datos.
Público

Usuarios a los que va dirigido

  • ClienteAprende a registrarse, pedir, pagar visualmente, seguir su pedido.
  • BaristaAprende a gestionar comandas en Kanban, turno/caja desde UI.
  • AdministradorConoce el panel y todas las secciones visibles.
  • CapacitaciónIdeal para inducción o consulta rápida.

3. Autenticación

Splash / Pantalla de carga inicial

Pantalla ui/splash/SplashScreen.kt

Descripción

Bienvenida

Al abrir la app se muestra el logo/marca Kaffa. Tras la verificación visual de estado, la app redirige al destino según rol o a Home/Login según corresponda.

  • AcciónEsperar carga inicial.
  • ResultadoRedirección automática al panel correspondiente.
Login

Inicio de sesión

Pantalla ui/auth/LoginScreen.kt

Paso a paso

Iniciar sesión

  • 1. Correo electrónicoEscribir el correo registrado.
  • 2. ContraseñaEscribir la contraseña (se puede mostrar/ocultar con el ícono).
  • 3. Olvidé mi contraseñaBotón "¿Olvidaste tu contraseña?" → Navega a recuperación.
  • 4. Iniciar SesiónBotón "Iniciar Sesión". Si éxito, redirige al Home/panel según rol.
  • 5. RegistrarseTexto "¿No tienes cuenta? Regístrate" → Navega a Registro.
Nota visual Si la cuenta no está verificada, aparece opción "Reenviar correo de verificación".
Registro

Registro de cliente

Pantalla ui/auth/RegisterScreen.kt

Paso a paso

Crear cuenta

  • 1. Ir a RegistroDesde Login → "Registrarse".
  • 2. Completar camposNombre completo, Correo electrónico, Contraseña.
  • 3. Crear cuentaPulsar "Crear cuenta".
  • 4. VerificaciónRevisar correo para activar cuenta. Tras registro, suele volver a Login.
Recuperación

Recuperar contraseña con Deep Link

Pantalla ui/auth/ForgotPasswordScreen.kt · MainActivity.kt (DeepLinks)

Flujo visual

kaffa://reset-password

  • 1. Solicitar enlaceDesde Login → "¿Olvidaste tu contraseña?" → Enviar solicitud.
  • 2. Abrir enlaceAl abrir el enlace kaffa://reset-password?token=...&correo=... la app lo parsea.
  • 3. RestablecerNavega a pantalla de restablecer contraseña con token/correo precargados.
  • 4. Volver a LoginTras restablecer correctamente, vuelve a Login limpio.

8. Guía rápida por tarea

"Recetas" para encontrar acciones al instante

Tarea Ruta / Pantalla Pasos (UI)
RegistrarmeLogin → RegisterCompletar datos → Crear cuenta → Verificar correo → Iniciar sesión.
Iniciar sesiónLoginCorreo + Contraseña → Iniciar Sesión.
Recuperar contraseñaLogin → ForgotPassword (o Deep Link)Solicitar enlace / Abrir kaffa://reset-password → Restablecer → Volver a Login.
Hacer un pedido (Cliente)Home/Productos → Detalle → Agregar → Carrito → Pagar (UI) → ConfirmarBuscar/categoría → Seleccionar → Ajustar cantidad → Agregar → Revisar carrito → Elegir método → Confirmar.
Seguir mi pedidoBottomBar "Pedidos" o Home → Mis PedidosAbrir pedido para ver estado/detalle.
Ver/promociones o eventosHomeRevisar popup al entrar o icono "Promociones y eventos".
Atender comandas (Barista)BaristaHome / PanelVer Kanban → Mover Recibido → En preparación → Listo → Entregado.
Hacer venta con POS (Barista)BaristaHome → POS / CajaAgregar productos → Carrito → Seleccionar pago (UI) → Confirmar.
Administrar productos/categoríasAdminPanel → Productos / CategoríasIr a sección → Gestionar desde listado (UI).
Cambiar temaPerfilPerfil → Alternar tema claro/oscuro.
